Presence 웨일 알바몬 연결 도우미 3.0 · 몽글이

이미 설치된 PC의 업데이트
1. whale://extensions 에서 Presence · 웨일 알바몬 연결의 새로고침(↻)을 누릅니다.
2. 알바몬 이력서 화면을 새로고침합니다.
3. 오른쪽 아래 졸고 있는 연보라 몬스터를 누릅니다.
4. '이력서 정보 가져오기'를 누르면 Crew Camp 창이 열리고 후보자 정보가 채워집니다.
5. 비공개 이름·번호는 알바몬에서 직접 열람하면 이어서 채워집니다.

새 권한은 추가하지 않습니다. 닫힌 메뉴에서 몬스터만 표시되며 클릭하면 눈을 뜨고 손을 흔듭니다.
ESC 또는 닫기로 접을 수 있고, 운영체제의 동작 줄이기 설정을 따릅니다.

설치 (PC 네이버 웨일 · Chrome 호환)
1. presence-albamon-helper.zip을 내려받아 압축을 풉니다.
2. 웨일 주소창에 whale://extensions 를 입력합니다. Chrome은 chrome://extensions 입니다.
3. 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드'를 선택합니다.
4. manifest.json이 들어 있는 폴더를 선택합니다.
5. 웨일에서 https://hub.presence.co.kr/recruiting/index.html 을 새로고침합니다.
6. Crew Camp의 이력서 링크 입력창에 알바몬 링크를 넣고 정보 불러오기를 누릅니다.

작동 범위
- HTTPS 알바몬 /human-resources/detail/ 이력서 페이지만 대상으로 합니다.
- 링크 가져오기를 요청한 이력서 탭에서 이름·나이·성별·안심번호·학력·경력·희망조건을 읽습니다.
- 다른 이력서 페이지에서는 자동 감지가 기본 꺼짐입니다. 해당 페이지에서 직접 켤 수 있습니다.
- 이름·번호가 가려져 있으면 공개된 학력·경력부터 채우고, 알바몬에서 사용자가 전화번호 보기 버튼을 누르면 나머지 정보도 이어서 채웁니다.
- 불확실하거나 누락된 필드는 비워 두므로 Crew Camp에서 확인합니다.
- 정보는 확장앱 메시지로 Crew Camp 탭에 전달합니다. 복구 시에만 URL fragment(#)를 사용하며 서버 요청 URL에는 포함하지 않습니다.
- 이름·연락처가 공개된 이력서를 가져오면 본인 계정의 후보자 정보와 당일 열람을 자동 기록합니다. 이름·연락처 공개 전에는 미리보기만 채우고 열람은 집계하지 않습니다.
- 도우미에서 이미 등록된 이력서를 열면 기존 후보자 창이 열립니다. 재열람은 '오늘 다시 열람'을 누릅니다.
- 자동 통화, 문자 발송, 카톡 발송, 폼 제출, 이력서 일괄 수집은 하지 않습니다.
- 이력서 화면 변경이나 팝업 구조에 따라 감지가 안 되면 '현재 이력서 기록'을 누르세요.
- 기존 2.0은 실제 웨일 로그인 이력서에서 정보 채우기를 확인했습니다. 3.0 몬스터의 화면·전달·공개 후 이어받기·기존 탭 재사용은 가상 데이터와 배포 파일로 검증했습니다. 기존 설치의 새로고침은 브라우저 관리 화면에서 직접 진행하세요.
- 매주 비밀번호가 바뀌면 알바몬에서만 다시 로그인하세요. 도우미는 비밀번호·쿠키를 읽거나 저장하지 않습니다.

권한
tabs: 요청한 이력서 탭을 열고 Crew Camp와 연결합니다.
storage: 5분 이내 가져오기 요청의 탭 ID·이력서 URL을 임시 관리합니다.
hub.presence.co.kr: Crew Camp 탭과 요청·응답을 주고받습니다.
알바몬 content script: 지정된 이력서 페이지에서만 버튼 감지와 화면 정보 추출을 수행합니다.

제거: whale://extensions에서 이 확장앱을 삭제하세요.
