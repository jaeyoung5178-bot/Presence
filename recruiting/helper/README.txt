Presence · 이력서 연결 도우미 4.0.1 · 몽글이

알바몬과 알바천국에서 직접 열어 본 개별 이력서를 Presence Crew Camp에 담습니다.
화면의 몽글이를 누르거나 Crew Camp에 이력서 링크를 붙여 넣어 가져올 수 있습니다.

4.0.1 수정: 알바천국의 '열람한 인재'에서 여는 팝업 이력서를 지원합니다.
이력서인데 목록 화면으로 잘못 표시되던 문제를 수정했습니다.
일반 화면과 팝업에서 같은 이력서를 열어도 adid가 같으면 동일 후보자로 연결합니다.

기존 사용자의 4.0.1 업데이트 (PC 웨일 / Chrome)
1. 새 presence-albamon-helper.zip을 내려받아 새 폴더에 압축을 풉니다.
2. whale://extensions (Chrome: chrome://extensions)를 엽니다.
3. 기존 Presence 알바몬 연결 도우미를 삭제하고 개발자 모드에서
   '압축해제된 확장 프로그램을 로드'로 새 manifest.json이 있는 폴더를 선택합니다.
   기존 폴더를 유지하려면 압축 안의 모든 파일을 기존 폴더에 덮어쓴 뒤
   확장앱 관리 화면의 새로고침(↻)을 눌러도 됩니다.
4. 3.1 이하에서 업데이트하면 알바천국 접근 권한이 추가됩니다.
   브라우저가 권한 확인을 요청하면 확인하세요. 4.0.0 대비 추가 권한은 없습니다.
5. Crew Camp와 열려 있는 알바몬·알바천국 이력서 페이지를 새로고침합니다.
   사이트 배포만으로 PC에 이미 설치한 도우미가 자동 업데이트되지는 않습니다.

처음 설치하기
1. presence-albamon-helper.zip을 내려받아 압축을 풉니다.
2. whale://extensions 또는 chrome://extensions에서 개발자 모드를 켭니다.
3. '압축해제된 확장 프로그램을 로드'에서 manifest.json이 있는 폴더를 선택합니다.
4. https://hub.presence.co.kr/recruiting/index.html 을 새로고침합니다.
5. 알바몬 또는 알바천국의 개별 이력서 링크를 넣고 '정보 불러오기'를 누릅니다.
6. 소스 사이트 로그인이 필요하면 '이력서 화면 열기'에서 로그인합니다.
   이름·번호가 공개되면 본인 계정의 후보자와 당일 열람이 자동 기록됩니다.

가져오는 정보
- 해당 사람의 이름, 나이, 성별, 공개된 휴대폰·안심번호, 학력, 경력, 희망 조건.
- 이름·번호가 가려진 상태는 공개된 항목을 미리보기로 채웁니다.
  이름과 번호를 소스 사이트에서 직접 열람하면 나머지도 이어서 채워집니다.
- 불확실하거나 보이지 않는 정보는 비웁니다. 가져온 뒤 Crew Camp에서 확인·수정할 수 있습니다.
- 알바천국은 실제 이력서 본문의 프로필·학력·경력·희망 조건 영역만 읽습니다.
  숨겨진 안내문의 번호, 고객센터, 추천 인재 정보는 가져오지 않습니다.
- 다른 사람으로 이동하면 자동 채우기가 꺼집니다. 각 이력서에서 직접 켤 수 있습니다.
- 재열람은 기존 후보자 창에서 '오늘 다시 열람'을 누릅니다.

지원 링크
- HTTPS www.albamon.com 또는 albamon.com /human-resources/detail/숫자
- HTTPS www.alba.co.kr 또는 alba.co.kr /resume/Detail?adid=이력서ID
- HTTPS www.alba.co.kr 또는 alba.co.kr /resume/popup/ResumeDetail?adid=이력서ID
- 팝업 주소를 입력하면 그 팝업 화면을 그대로 엽니다.
- 알바천국의 adid는 후보자 구분에 반드시 보존합니다. useai, inflowtype 등
  추적용 매개변수는 제거합니다. 목록, 채용공고, 로그인, 외부 사이트는 가져오지 않습니다.
- 모바일 알바천국 도메인과 다른 서브도메인은 현재 지원하지 않습니다.

권한과 동작 범위
- tabs: 사용자가 요청한 이력서 탭을 열고 Crew Camp와 연결합니다.
- storage: 5분 이내 요청의 탭 ID·이력서 주소를 임시 관리합니다.
- hub.presence.co.kr: 본인 계정의 Crew Camp 탭과 요청·응답을 주고받습니다.
- 알바몬·알바천국: 해당 사이트의 화면에 몽글이를 표시하고,
  지원되는 개별 이력서 페이지에서만 정보 추출을 수행합니다.
- 127.0.0.1: 로컬 개발 검증용이며 운영 계정 정보에 별도 접근하지 않습니다.
- 비밀번호·쿠키를 읽거나 저장하지 않습니다. 로그인은 원래 사이트에서 진행합니다.
- 유료 열람·연락처 공개 버튼을 자동으로 누르지 않습니다. 열람 권한이 필요한 경우
  사용자가 해당 사이트에서 직접 완료해야 합니다.
- 이력서 일괄 수집, 자동 통화·문자·카톡 발송, 폼 제출은 하지 않습니다.
- 정보는 확장앱 메시지로 전달합니다. 복구 시 URL fragment(#)를 이용할 수 있으며,
  fragment의 정보는 서버 요청 주소에 포함되지 않습니다.

화면이 바뀌어 감지가 안 되면 이력서를 새로고침하고 '이력서 정보 가져오기'를 누르세요.
ESC 또는 닫기로 몽글이 메뉴를 접을 수 있고 운영체제의 동작 줄이기 설정을 따릅니다.
제거하려면 확장앱 관리 화면에서 이 확장앱을 삭제합니다.
