Presence 알바몬 모집 도우미 1.0

설치 (PC Chrome)
1. presence-albamon-helper.zip을 내려받아 압축을 풉니다.
2. Chrome 주소창에 chrome://extensions 를 입력합니다.
3. 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드'를 선택합니다.
4. manifest.json이 들어 있는 폴더를 선택합니다.
5. 열려 있던 알바몬 이력서 페이지를 새로고침합니다.
6. 오른쪽 아래 'Presence 기록 켜기'를 누릅니다.

작동 범위
- HTTPS 알바몬 /human-resources/detail/ 이력서 페이지만 대상으로 합니다.
- 자동 감지는 기본 꺼짐입니다. 이력서별로 직접 켜야 합니다.
- 전화번호 보기/연락처 확인 버튼 클릭 후 현재 화면에 표시된 번호와 이름·나이·성별을 읽습니다.
- 불확실하거나 누락된 필드는 비워 두므로 Crew Camp에서 확인합니다.
- 정보는 URL fragment(#)로 기존 Crew Camp 탭에 전달합니다. 서버 요청 URL에는 포함하지 않습니다.
- Crew Camp에서 실제 저장을 눌러야 본인 계정에 저장되고 열람 횟수로 집계됩니다.
- 도우미에서 이미 등록된 이력서를 열면 기존 후보자 창이 열립니다. 재열람은 '오늘 다시 열람'을 누릅니다.
- 자동 통화, 문자 발송, 카톡 발송, 폼 제출, 이력서 일괄 수집은 하지 않습니다.
- 이력서 화면 변경이나 팝업 구조에 따라 감지가 안 되면 '현재 이력서 기록'을 누르세요.
- DOM 추출은 실제 알바몬 로그인 화면에서 검증이 필요합니다. 추출값을 반드시 확인해 주세요.

권한
tabs: 열려 있는 Crew Camp 탭을 찾아 갱신합니다.
hub.presence.co.kr: Crew Camp 탭을 재사용합니다.
알바몬 content script: 지정된 이력서 페이지에서만 버튼 감지와 화면 정보 추출을 수행합니다.

제거: chrome://extensions에서 이 확장 프로그램을 삭제하세요.
