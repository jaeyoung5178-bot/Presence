# 푸켓에서 가져온 세 가지 선물

Presence Hub의 기존 키노트 엔진을 쓰는 13장, 약 15분 발표입니다. 실제 여행 사진·영상, 수동으로 크게 재생하는 인트로와 12초 엔딩, 자연스러운 한국어 발표 원고를 포함합니다. 여행 슬라이드 2·3·4·12는 큰 사진 한 장과 보조 사진 두 장의 정적 포토 프레임입니다.

## 발표하기

상단 전체화면을 누르고 인트로 **크게 재생**을 선택합니다. 영상이 끝나거나 Escape로 닫으면 발표로 돌아옵니다. 방향키·스와이프로 이동하고 N으로 원고, F로 전체화면을 엽니다. 인트로와 엔딩은 자동으로 재생하지 않으며 슬라이드를 벗어나면 정지합니다. 하단 타이머와 원고의 권장 구간으로 15분 리허설을 할 수 있습니다. 원고 창은 청중에게도 보입니다.

**발표 준비**에서 미디어, 슬라이드 순서, 원고, 실행 계획의 담당자·시작일·지표를 바꿀 수 있습니다. 순서와 원고는 슬라이드 고유 ID로 연결됩니다. 편집 내용과 업로드는 해당 브라우저에만 저장됩니다. 저장 공간을 사용할 수 없어도 포함된 기본 미디어는 표시됩니다. 미입력 실행 계획은 청중 화면에 표시하지 않습니다.

## 강연 근거

원본은 자동 전사여서 발언을 직접 인용한 것으로 소개하지 않습니다. 강연자 이름은 정확성을 확정할 수 없어 생략했습니다. 약속·참석·첫 출근 기록, 팀원별 경험, 주간 점검은 발표자가 팀에 제안할 적용입니다. 확정하지 않은 팀 수치·담당자를 넣지 않았습니다. 사실과 적용의 구분은 원고와 준비 화면에 남겼습니다.

## 장식 자산

`phuket-frame.png`와 `jetski-sticker.png`는 OpenAI image_gen으로 생성한 열대 포토 프레임 장식입니다. 실제 여행 사진으로 사용하지 않습니다. 여행 파트에는 야자수·꽃·티켓·파도·제트스키가 은은하게 움직이고, 학습 파트에서는 낮은 대비로 남습니다. 모션 OFF와 동작 줄이기 설정을 준수합니다.

시각적 참고: [Canva travel scrapbook](https://www.canva.com/scrapbooks/templates/travel/), [Boothsummer tropical frames](https://www.boothsummer.com/en/frames). 참고 이미지를 복사하지 않았습니다.
