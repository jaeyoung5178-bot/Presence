PROCESS

기록에서 확인한 단계별 전환

앞·뒤 단계가 모두 입력된 시간 행과 사진의 하루 합계를 사용해요. 같은 기록에 직접 입력한 단계가 있으면 그 사진의 합계는 중복 합산하지 않아요. 후원 전환으로 해석하지 않으며, 분모가 0이면 계산하지 않아요.

분석 기준과 포함된 기록

저장된 내 콜백싯만 분석해요. 미저장 초안은 제외하고, 같은 ID와 동일한 원본 사진은 한 번만 셉니다. 같은 날짜의 서로 다른 기록은 합산해요.

각 수치는 직접 입력한 시간별 합계를 우선하고, 입력이 없는 항목은 사진에서 읽은 하루 결과를 사용해요. 목표는 결과에 더하지 않으며, 하루 합계를 시간별로 나누어 만들지 않아요. 읽지 못한 값은 0이 아닌 미확인으로 남겨요.

후원자 수는 체크한 케이스·특이사항 → 직접 입력한 Rehash → 사진에서 다시 확인한 Rehash 순으로 사용해요. 새로 읽은 기록이 없는 사진만 기존 확인값을 사용해요. 새 전사에서 Rehash를 판독하지 못했다면 이전 추정값도 사용하지 않아요.

일평균은 해당 수치가 확인된 날짜 수로 나눠요. 이전 비교 기간은 바로 앞의 같은 일수이며, 기간마다 기록량과 입력 충실도가 다를 수 있어요. 증감이 실제 성과의 원인이나 능력 평가를 뜻하지는 않아요.

회고는 직접 입력한 문장을 우선하고, 빈칸에는 사진에서 읽은 문장을 사용해요. 키워드와 반복 횟수를 정리한 규칙 기반 요약이며 각 인용에 날짜와 출처를 표시해요. 연습 제안은 그 기록을 바탕으로 시도해 볼 행동이에요. 읽지 못한 스킬·태도는 추측하지 않아요.
