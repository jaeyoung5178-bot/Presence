BEFORE SETUP

5분 현장 체크

거리뷰는 계절과 촬영 시점이 다릅니다. 실제 설치 전에는 정오와 오후 시간대에 한 번씩 확인하세요.

  1. 경계점포 대지와 공공보도의 경계를 지적도로 확인
  2. 그늘12–16시 중 부스 전체가 들어가는지 확인
  3. 동선출입문·점자블록·버스정류장·소화전 이격
  4. 폭설치 후 보행 유효폭 2m 이상을 보수적으로 확보
  5. 승인관할 구청 도로부서와 인접 점포에 사전 확인
