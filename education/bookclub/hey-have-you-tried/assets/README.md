# 『정주영 이봐, 해봤어?』 장면 에셋

제목과 본문은 HTML로 유지하고, 공통 키노트 엔진의 탐색·책 표지 넘김·모션 OFF를 재사용합니다. 출처 URL, 원본 URL, 수집일, SHA-256 및 원본 크기는 `prompts.json`에 기록했습니다.

| 파일 | 쓰임 | 원본과 성격 |
| --- | --- | --- |
| `cover.jpg` | 서가와 첫 장의 실제 책 표지 | 알라딘 2015년판 종이책 카탈로그 |
| `jubail.png` | 중동·주베일 장면 | HD현대중공업 공식 역사 일러스트. 실제 사진으로 표시하지 않음 |
| `shipyard.png` | 조선소·유조선 장면 | HD현대중공업 공식 역사 일러스트. 실제 사진으로 표시하지 않음 |
| `pony-production.jpg` | 포니 생산 장면 | 현대자동차그룹 공식 기술사에 게재된 생산 라인 기록 사진 |

모든 파일은 원본 바이트를 보존했습니다. 합성이나 생성형 이미지 편집 없이 CSS의 배치·크롭·명도 오버레이만 적용했습니다. 표지의 책 구조와 18초 빛, 주베일의 18초 운송 표시, 마지막 장의 제도용 격자는 책별 CSS로 제작했습니다. 애니메이션은 모션 OFF와 동작 줄이기 설정을 따릅니다.

이미지 출처 표기를 HTML·발표 원고·출처 창에 함께 유지합니다. 공개 웹사이트에 게재된 자료라는 사실이 별도의 자유 이용 허락을 뜻하지는 않습니다.
