# Presence Reading Room · 서가 등록 안내

독서발표회는 완성된 발표를 실제 책처럼 쌓아 가는 서가입니다. 서가, 발표 엔진, 책별 콘텐츠를 나누어 다음 책에도 같은 골조를 사용합니다.

## 파일 역할

| 파일 | 역할 |
| --- | --- |
| `catalog.js` | 출간 정보, 실제 표지 URL, 완성된 발표의 경로 |
| `gallery.js` | 서가 HTML 생성, 카운트, 표지 실패 시 대체 표지, URL 및 텍스트 검증 |
| `gallery.css` | 책등·페이지·표지의 입체 표현, PC·태블릿·모바일 서가 |
| `shared/` | 책들이 함께 쓰는 발표 골조와 제작 도구 |
| `<책의-slug>/` | 각 책의 발표, 콘텐츠 설정, 장면별 에셋, 발표 원고 |

갤러리는 정적 JavaScript로 동작합니다. `file://`로 열어도 JSON 요청이나 별도 서버 없이 사용할 수 있습니다. 교육 자료의 Firebase 저장값이나 관리자 권한은 변경하지 않습니다.

## 다음 책을 추가하는 순서

1. `shared/`의 제작 안내에 따라 새 책의 발표 폴더를 만듭니다. 초안을 만들었다고 서가에 자동 등록하지 않습니다.
2. 책별 설정인 `window.PresenceBook`에 제목·저자·도입 원고·장별 노트·키워드·출처를 넣고 장면마다 의미에 맞는 에셋을 준비합니다.
3. 인용 문장과 쪽수는 해당 판본에서 검증하고, 표지는 실제 책의 이미지인지 확인합니다. 판본이 바뀌면 표지·ISBN·발행연도·인용 쪽수를 함께 확인합니다.
4. 발표와 자료가 완성되면 `catalog.js`의 `books` 배열에 항목을 한 개 추가합니다. 준비 중인 항목은 `status: 'draft'`로 두면 노출되지 않습니다.
5. 갤러리에서 책 클릭 → 발표 첫 장 → 서가 복귀를 확인합니다. 390×844, 1024×768, 1440×900에서 제목·본문·버튼이 겹치지 않는지 확인한 뒤 배포합니다.

`href`는 **항상 `index.html`까지** 적습니다. 디렉터리 링크만 쓰면 로컬 파일로 볼 때 발표 대신 폴더가 열릴 수 있습니다.

## 등록 형식

아래 예시는 설명용입니다. 실재하는 책의 정보로 교체하고, 발표가 완성되기 전에는 `ready`로 바꾸지 않습니다.

```js
Object.freeze({
  slug: 'next-book',
  status: 'draft',
  title: '실제 책 제목',
  originalTitle: '원서 제목',
  author: '저자',
  translator: '번역자',
  publisher: '출판사',
  edition: '인용을 확인한 판본',
  year: 2026,
  isbn: '검증한 ISBN',
  cover: 'https://실제-제공처/표지.jpg',
  source: 'https://출간-정보를-확인한-페이지',
  presentationTitle: '이 책의 발표 제목',
  description: '발표의 핵심 관점',
  tags: Object.freeze(['핵심 개념', '실천']),
  slides: 9,
  introMinutes: 3,
  href: 'education/bookclub/next-book/index.html#slide-1'
})
```

필수 노출 조건은 `status: 'ready'`, 비어 있지 않은 `title`과 `author`, 안전한 발표 경로입니다. 배열 순서가 서가 순서와 `VOL. 001` 번호를 결정합니다. 등록 수, 독서발표회 탭 수, 전체 자료 수는 이 배열에서 계산합니다. 가상의 책이나 미완성 발표는 독자가 클릭할 수 있는 책으로 표시하지 않습니다.

## 표지와 에셋

- 현재 『퓨처 셀프』는 **30만 부 기념 스페셜 에디션**의 실제 표지입니다. 벤저민 하디 지음, 최은아 옮김, 상상스퀘어, 2024년, ISBN `9791198854315`.
- 출간 정보: <https://www.yes24.com/Product/Goods/133809700>
- 표지: <https://image.yes24.com/goods/133809700/XL> — 2026-09-28 로딩 검증, 838×1200 JPEG.
- 표지는 제공처의 HTTPS URL을 직접 사용합니다. 보유한 사용 가능 이미지가 있다면 `education/bookclub/<slug>/assets/cover.webp` 같은 로컬 이미지 경로도 사용할 수 있습니다.
- 외부 표지를 불러오지 못하면 제목과 저자를 담은 대체 표지가 남습니다. 대체 표지는 실제 출간 표지의 복제본으로 주장하지 않으며, 발표 링크와 서지 정보는 계속 작동합니다.
- 장면 배경은 표지와 별도입니다. 각 책의 `assets/`에 보관하고, 같은 책에서도 장면 의미에 맞추어 다르게 배치합니다. 발표용 생성 에셋을 실제 출간 표지로 쓰지 않습니다.

## 재사용 API

```js
PresenceBookGallery.render({ compact: false }); // 독서발표회 탭의 전체 서가
PresenceBookGallery.render({ compact: true });  // 교육 전체 탭의 작은 책 카드
PresenceBookGallery.count();                   // 검증된 ready 항목 수
PresenceBookGallery.setContext(active, educationItemCount);
```

반환 HTML에 들어가는 모든 콘텐츠 필드는 이스케이프됩니다. 발표 경로는 `education/bookclub/<slug>/index.html#slide-N` 형식만 허용하고, 이미지에는 HTTPS 또는 책 폴더의 이미지 경로를 사용합니다. 빈 서가, 카탈로그 오류, 표지 로딩 실패를 각각 처리합니다. 다음 책의 빈 자리는 설명용이며 클릭 가능한 가짜 자료가 아닙니다.

## 화면 원칙

실제 표지 → 제목·저자 → 발표 주제 → 발표 시작 순서로 읽힙니다. 전체 책 카드가 하나의 링크이므로 표지 어디를 눌러도 한 번에 시작합니다. 호버는 가벼운 책 기울기만 더하며, 정보와 기능은 터치에서도 모두 보입니다. 동작 줄이기 설정에서는 기울기 애니메이션을 끕니다.

PC와 태블릿은 책을 나란히 놓고, 모바일은 한 권씩 세로로 보여줍니다. 모바일의 다음 책 자리는 작은 책등 형태로 접어 불필요하게 긴 빈 공간을 만들지 않습니다.
