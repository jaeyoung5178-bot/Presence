# 독서발표회 작업 지침

사용자는 이 독서발표회를 다음 책에도 계속 이어 쓸 수 있는 하나의 발표 시스템으로 요청했습니다. 이 디렉터리에서의 새 책 추가와 수정은 아래 계약을 따릅니다.

- 공통 엔진·반응형 레이아웃·원고·타이머·키보드/터치 탐색은 `shared/`를 재사용합니다. 책별로 엔진 복사본을 늘리지 않습니다.
- 다음 책은 `template/create-book.cjs`로 시작합니다. 책마다 별도 폴더에 `index.html`, `book.js`, 원고, `assets/`를 둡니다. 골조는 `shared/ASSET_GUIDE.md`를 따릅니다.
- 장 수는 고정하지 않습니다. 공통 컨트롤은 `.slide` 개수와 책의 설정을 사용합니다. 콘텐츠·키워드·원고·출처는 각 책의 `book.js`와 HTML에서 관리합니다.
- 에셋은 핵심 콘텐츠입니다. 같은 배경을 모든 장에 복제하지 않고, 인용과 클로징의 의미에 맞는 서로 다른 장면을 제작합니다. 책마다 고유한 이미지·색·표지를 사용하고, 배치·명도·여백의 골조를 공유합니다.
- 인용은 정확한 문장·판본·쪽수·출처를 함께 확인합니다. 출처가 쪽수 범위를 제시하면 그대로 표기합니다. 확인하지 않은 쪽수나 원문을 추정하지 않습니다.
- 직접 인용, 책을 설명하는 새 요약, 발표자의 감상과 실천을 구분합니다. 요약은 책의 중심 논지와 연결되는 근거를 갖춥니다.
- 갤러리는 책 표지·제목·저자를 중심으로 책이 한 권씩 쌓이는 형태를 유지합니다. 클릭하면 해당 책의 발표가 시작되어야 합니다. 실제 카탈로그 구조와 갤러리 문서를 먼저 읽고, 준비가 끝난 책만 등록합니다.
- 이미지 프롬프트와 제작 도구·원본 위치·배포 변환을 기록합니다. 텍스트는 이미지에 굽지 않고 HTML로 유지합니다.
- 모바일 390×844, 태블릿 1024×768, PC 1440×900에서 검증합니다. 번호 겹침, 좁은 화면의 단어 붙음, 잘린 컨트롤, 낮은 본문 대비, 수평 넘침을 해결합니다. 모션 OFF와 동작 줄이기 설정을 지킵니다.
- 기존 책과 다른 작업자의 변경을 보존합니다. 완성된 콘텐츠와 검증된 범위만 배포합니다.
